## Requirement
- Docker or Redis
- Nodejs
## Installation
Make data example from extract file log_.zip

Clone the repository:
```bash
git clone https://github.com/BerlitzPlatina/hyperloglog.git
cd hyperloglog
```
Make file .env:
```bash
cp .env.example .env
```
Run docker compose:
```bash
docker compose up
```
## Usage
Run file node.js:
```bash
node node.js
```
